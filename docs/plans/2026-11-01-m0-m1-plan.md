# Arioso M0 and M1 Implementation Plan

**Goal:** a working local speech stack, built in the order the PRD sets out: model
management first, then Piper text to speech behind an HTTP and WebSocket API.

**Architecture:** a Cargo workspace of small crates. Engines sit behind traits in
`arioso-core`; `arioso-models` owns the catalog, cache, and downloads; `arioso-cli`
is the binary; `arioso-server` (M1) exposes the HTTP surface. No crate reaches into
another's internals.

**Stack:** Rust 2024 edition, tokio, reqwest with rustls, ed25519-dalek for manifest
signatures, ort for ONNX inference, axum for HTTP, utoipa for OpenAPI.

**Status:** M0 is done except the signing tool and the server-side progress feed.
M1 tasks 1.1 to 1.3 are done: the phoneme table, the CMUdict loader, and the
ARPAbet mapping. The chain was checked end to end on the real voice and the real
dictionary; every symbol resolved. M1 resumes at task 1.4, the sentence chunker.

## M1. Piper text to speech

Each task is one commit. Run the listed test after every step.

### Task 1.1: Phoneme mapping table

**Objective:** turn the model's `phoneme_id_map` JSON into a lookup the engine can use.

**Files:**
- Create: `crates/arioso-g2p/src/lib.rs`
- Create: `crates/arioso-g2p/Cargo.toml`
- Test: inline `#[cfg(test)]`

**Steps:**
1. Write a failing test that parses
   `{"phoneme_id_map":{"^":[[0]],"h":[[20]]," ":[[3]]}}` and asserts `id_of('h') == Some(20)`.
2. Implement `PhonemeMap::from_json(&str)` and `PhonemeMap::id_of(char) -> Option<u32>`.
3. Run `cargo test -p arioso-g2p`, expect 1 passing test.
4. Commit: `feat(g2p): parse the model phoneme id map`.

### Task 1.2: CMUdict loader

**Objective:** read the BSD-licensed pronunciation dictionary into memory.

**Files:**
- Create: `crates/arioso-g2p/src/cmudict.rs`
- Test: `crates/arioso-g2p/tests/cmudict.rs` with a 20-line fixture

**Steps:**
1. Failing test: `"hello"` maps to `HH AH0 L OW1`.
2. Implement `CmuDict::parse(&str)` and `CmuDict::lookup(&str) -> Option<&[Phoneme]>`.
3. Handle the `WORD(2)` alternate-pronunciation suffix.
4. Run `cargo test -p arioso-g2p`, expect 2 passing tests.
5. Commit: `feat(g2p): load CMUdict`.

### Task 1.3: ARPAbet to the model's IPA inventory

**Objective:** map CMUdict output onto the characters the Piper voice expects.

**Files:**
- Create: `crates/arioso-g2p/src/arpabet.rs`

**Constraint found while checking the real voice:** `en_US-lessac-medium` maps 154
single symbols. There is no entry for `aɪ`, `oʊ`, `tʃ`, `dʒ`, `eɪ`, `ɔɪ`, `aʊ`, or
`iː`, because those are sequences of single symbols with `ː` appended for length.
The mapping must therefore emit one symbol at a time: `EY` becomes `e` then `ɪ`,
`CH` becomes `t` then `ʃ`, and stress is a separate `ˈ` or `ˌ` symbol placed before
the syllable.

**Steps:**
1. Failing test: `HH AH0 L OW1` becomes `h ə l ˈ o ʊ`, with the stress mark its own
   symbol and the diphthong split.
2. Failing test: every symbol the mapping can emit is present in the voice
   inventory. Embed the 154-symbol list as a constant in the test; it is derived
   data, not a model weight.
3. Implement the table, then drop phonemes the model does not know.
4. Run `cargo test -p arioso-g2p`.
5. Commit: `feat(g2p): map ARPAbet to the voice inventory`.

Rhoticity and vowel length are judgement calls until the golden-audio test in task
1.5 can judge them: `ER` is written `ɚ` when unstressed and `ɜ` plus `ɹ` when
stressed, and that choice needs an ear, not a table.
